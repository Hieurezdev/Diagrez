# ACE Playbook: Class Diagram

## NOTATION RULES

- [not-00002] helpful=0 harmful=0 :: Generalization points from the specialized class to its general parent.
- [not-00003] helpful=0 harmful=0 :: Use three class compartments: name, attributes, and operations; show visibility with UML symbols.
- [not-00004] helpful=0 harmful=0 :: Use a hollow triangle for generalization, a hollow diamond for aggregation, a filled diamond for composition, and a dashed arrow for dependency.
- [not-00005] helpful=0 harmful=0 :: Render each class with name, attributes, and operations compartments; italicize abstract class names and show visibility as +, -, #, or ~.
- [not-00006] helpful=0 harmful=0 :: Put relationship names, roles, and multiplicities at the ends or middle of the association line when the model supplies them.

## SEMANTIC CHECKS

- [sem-00001] helpful=0 harmful=0 :: Use composition only when the part cannot meaningfully outlive the whole.
- [sem-00002] helpful=0 harmful=0 :: Keep relationships between declared classes and use association for a plain structural link without stronger ownership semantics.
